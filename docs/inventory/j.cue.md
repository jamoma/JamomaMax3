# j.cue (old behaviour, read for milestone 4)

Sources: `JamomaMax/source/j.cue/j.cue.cpp` (564 lines), `PeerObject/TTCueManager.cpp`, `TTCue.cpp`; sample text cue files `Jamoma/examples/model features/alias_renaming.cues.txt` and `Jamoma/patchers/models/data/cue_script/cue_script.demoscript.txt`; the help `j.cue.maxhelp`.

## Object
- Outlets: line (0, what a recalled cue sends: commands `<address> <value...>`), dump (1: `names <cue names>`, `read`, `error`, `get` answers). Argument: one symbol, the name of the shared namespace (selection) the cue stores from; the same as `@namespace`; without one an internal default namespace is used.
- Messages (class wrapper passes the cue manager's attributes and messages through): `clear`, `store <name>`, `recall <name|n> [start address]`, `output <name|n>`, `interpolate`, `mix`, `move`, `remove`, `rename`, `copy`, `sequence`, `namespace/clear|append|remove|select`, `get <attribute> <cue>`, `set <attribute> <cue> <value...>` (a cue has `name`, `description`, `ramp`), `read [file]`, `write [file]`, `read/again`, `write/again` (all four are deferred), `edit`/`dblclick` (opens a text editor window on the cue list or one cue; `edclose` reads the text back).
- `store <name>`: a new cue is appended to the order (`order`, `current`, `currentPosition` are updated); an existing one is cleared and stored again. It stores, for every address that is **selected** in the namespace, the current value (and unit, ramp) of that parameter; with `ramp` set on the cue every line gets `ramp <ms>`. `recall`: by name or 1-based position, optionally only the line at an address; the cue is flattened first (sub-scripts per model merged), then every line is run in order. A cue is a script of lines `<address> <value...>` with flags `cue <name>` and `description <text>`.
- Text file (`WriteAsText`/`ReadFromText`, read from the samples): a line `CUE <name>` starts a cue (a trailing `# (fold)` comment is ignored), lines below it are commands `<absolute address> <value...>`; `#` starts a comment; blank lines and `#####` rules are ignored; `# (end)` ends the cue; indentation is free.
- XML file (`WriteAsXml`/`ReadFromXml`, TTCueManager.cpp:924-1036): one `<cue name="...">` element per cue, in order, with the same content as a preset's (`<flag name="description">`, `<command address=".." unit=".." ramp="..">`, `<script address="..">`). After reading, the first cue becomes current and the namespace is set to the first cue's addresses. **The root element of the file is written by the generic XML handler, not by the cue manager: to characterise in Task 5 from the existing preset XML code** (`core/src/preset_files.cpp`), which writes the same child elements.
- `edit`: the editor shows the text form; closing reads it back (`edclose`).

## Rulings
1. **Built:** `store`, `recall` (with a start address), `output`, `interpolate`, `mix`, `move`, `remove`, `rename`, `copy`, `clear`, `get`, `set`, `read`, `write`, `read/again`, `write/again`, `edit`/`dblclick`/`edclose`, the namespace messages, the text and XML files, `names` on the dump outlet. The cue manager reuses the preset machinery (a cue is a preset with absolute addresses).
2. **`sequence` is not built** (timed running of cues: not read; the old help patcher examples to be checked in Task 9; if one needs it, it stays a placeholder). Listed in `docs/changes.md`.
3. **Selection comes from `j.namespace`'s shared selection** (`j.namespace.md`, Ruling 2). A cue without a namespace stores the selection of its own default namespace, which is empty until `namespace/append` is sent; storing an empty selection stores an empty cue and says so on the console.
4. Recall of an address that no longer exists is skipped and reported (as presets do); it is not an error for the rest.
5. File dialogs: `read`/`write` without an argument open the Max file dialog (as the old); with a file name no dialog. Files are never written unasked.
6. The XML root element and attribute spelling follow the preset XML code in the core (the same writer); a file written by the old software is not available, so this is checked only against the old writer's source, as for presets.
